# **Student_Management_System**

## ***Description***

**Student Database App** is a simple _Java console-based application_ designed to simulate a student enrollment and tuition management system. It allows an administrator to:

- Log in securely
- Enroll students in courses
- Process tuition payments
- View student information

---

## ***Features***

- **Admin Login System**
  - Secure access using predefined credentials
- **Student Enrollment**
  - Register multiple students
  - Input student details (first name, last name, grade year)
  - Generate a unique student ID
- **Course Enrollment**
  - Enroll in multiple predefined courses
  - Fixed tuition cost per course
- **Tuition Payment**
  - View balance
  - Pay tuition
- **Student Overview**
  - Display all student data including courses and balance
